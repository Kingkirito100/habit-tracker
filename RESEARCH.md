# RESEARCH

> Конспект составлен по общим знаниям о продуктах и платформах, без живой проверки сторов на момент написания. Перед релизом стоит освежить пункты про iOS/PWA.

## Паттерны трекеров (Streaks, Habitify, Habitica, Finch, TickTick, Productive, Way of Life)
1. **Список с одним тапом на главном экране.** Отметка — главное действие; графики вынесены на отдельный экран.
2. **Серия — вторична и «прощающая».** Лучшие приложения допускают пропуск, недельные цели, восстановление. Принято: пропуск до 2 раз в неделю не обрывает серию.
3. **Календарь/сетка истории с ретро-правкой.** Забытый день можно поправить. Принято: цикл по тапу «выполнено → пропуск → пусто».
4. **Количественные привычки с дефолтом.** Один тап ставит цель целиком, «±» корректирует.
5. **Мягкий тон.** Пропуск — часть процесса, поэтому янтарный пунктир, а не красный.

## Apple HIG (Apple-inspired, не клон)
Clarity / Deference / Depth: системный шрифт, крупные заголовки, сегментированный контрол, нижний tab bar из 3 вкладок, тёмная тема, акцент только для смысловых состояний.

## Microsoft Fluent (оболочка)
Командные действия рядом с контентом (навигация периода + «Сегодня»), слои (панели), предсказуемые повторяемые действия. Стили на одном экране не смешиваются.

## PWA 2026
- Web Push на iOS — только из установленного на домашний экран PWA (iOS 16.4+), разрешение — только по действию пользователя.
- На iOS нет `beforeinstallprompt` → статичная инструкция через «Поделиться».
- HTTPS обязателен (на Vercel есть по умолчанию).
- Не просить разрешения на первом холодном визите: сначала ценность.

## Переключение представлений
Один сегментированный контрол (День/Неделя/Месяц/Год), режим сохраняется, свайп между периодами, кнопка «Сегодня», пикер месяца.

## Граница MVP / v2
**MVP (сделано):** гостевой режим, офлайн, 4 представления, серии с пропусками, инсайты, кастомизация, install prompt, локальные напоминания, резервная копия файлом, каркас Web Push в service worker.
**v2:** аккаунты и синхронизация (Supabase), серверная рассылка push, недельные цели, drag-and-drop порядка, виджеты.
