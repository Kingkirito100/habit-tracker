# SCRATCHPAD

## Сделано
Исследование, токены, scaffold (Next 15 + Serwist), Dexie-слой, экран «Сегодня», представления день/неделя/месяц/год, детали привычки, инсайты, настройки (тема, акцент, плотность, порядок, архив), install prompt, запрос уведомлений после первого чекина, локальные напоминания, service worker с push-обработчиком, офлайн-страница, резервная копия JSON. `npm run build` проходит; страницы и `sw.js` отдаются со статусом 200.

## Версия 2 (добавлено)
Частота привычек (ежедневно / по дням / N в неделю / N в месяц), серии по неделям и месяцам, мини-календарь с серией на главной, цвет привычки, шаблоны, вехи, кольцо дня, стили Стекло и Неон. Логика серий проверена скриптом на примерах (weekly, days, monthly, daily со skip).

## Не проверено
Внешний вид стилей Стекло и Неон на устройствах, установка на реальные iOS/Android, доставка push, поведение свайпов на устройстве, Lighthouse/контраст в разных акцентах.
