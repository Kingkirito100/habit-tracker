# SCRATCHPAD

## Сделано
Исследование, токены, scaffold (Next 15 + Serwist), Dexie-слой, экран «Сегодня», представления день/неделя/месяц/год, детали привычки, инсайты, настройки (тема, акцент, плотность, порядок, архив), install prompt, запрос уведомлений после первого чекина, локальные напоминания, service worker с push-обработчиком, офлайн-страница, резервная копия JSON. `npm run build` проходит; страницы и `sw.js` отдаются со статусом 200.

## Не проверено
Установка на реальные iOS/Android, доставка push, поведение свайпов на устройстве, Lighthouse/контраст в разных акцентах.

3. Серверный push (см. README).
