# Трекер привычек (PWA)

Офлайн-first трекер: один тап — отметка, серии с пропусками, представления день/неделя/месяц/год, инсайты, темы и акценты. Данные хранятся на устройстве (IndexedDB), регистрация не нужна.

## Запуск
```bash
npm install
npm run dev        # http://localhost:3000 (service worker в dev выключен)
npm run build && npm start   # production, тут работают PWA и офлайн
npm run lint       # проверка типов
```

## Выложить в сеть: GitHub → Vercel
1. Создайте репозиторий на GitHub и загрузите содержимое этой папки (`node_modules` и `.next` в `.gitignore`).
2. На vercel.com: *Add New → Project* → выберите репозиторий → *Deploy*. Настройки по умолчанию подходят.
3. Откройте выданную ссылку на телефоне (HTTPS уже включён).

## Установка на телефон
- **Android (Chrome):** после первой отметки появится баннер «Установить на телефон» или меню ⋮ → «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран Домой». Уведомления на iOS работают только из установленного приложения.

## Проверка офлайна
Откройте установленное приложение с сетью, пройдитесь по вкладкам, затем включите авиарежим и откройте снова. Главный экран, настройки и данные должны работать. Если страница ещё не посещалась, покажется экран «Нет сети».

## Напоминания
- Время задаётся в форме привычки. Разрешение запрашивается кнопкой после первого чекина или в «Настройки → Напоминания».
- **Пока приложение открыто** напоминания приходят локально (одно на привычку в день).
- **Push при закрытом приложении** требует сервера. Готово на клиенте: подписка (`lib/notifications.ts`) и обработчик `push` в `app/sw.ts`. Осталось:
  1. `npx web-push generate-vapid-keys` → публичный ключ в `NEXT_PUBLIC_VAPID_PUBLIC_KEY` (Vercel → Settings → Environment Variables), приватный держите на сервере.
  2. Эндпоинт, принимающий подписку (`NEXT_PUBLIC_PUSH_ENDPOINT`), и база для хранения (например, Supabase).
  3. Планировщик, который в нужное время вызывает `web-push` с JSON `{title, body, url}`. Cron на бесплатном Vercel срабатывает не чаще раза в сутки — для точного времени возьмите pg_cron в Supabase или внешний планировщик.

## Структура
`app/` — экраны и service worker (`sw.ts`) · `components/` — UI · `lib/` — данные (Dexie), серии, представления, уведомления, настройки · `ui/tokens.css` — дизайн-токены · `public/` — manifest и иконки.

## Не реализовано
Аккаунты и синхронизация (вместо них — резервная копия JSON в настройках), серверный push, drag-and-drop порядка (кнопки ↑↓).
