# Трекер привычек — правила проекта

- Next.js 15 (App Router) + TypeScript + Tailwind 3 + Dexie + Serwist. Без бэкенда в MVP.
- Один тап — отметка. Без диалогов подтверждения. Optimistic update в `HabitCheckIn`.
- Три состояния в сетках (выполнено / пропуск / впереди) различаются формой, не только цветом. Красный для «пропуска» не используем.
- Цвета — только через токены (`ui/tokens.css`, Tailwind-алиасы `bg-surf`, `text-ok` …). Хардкод цветов в компонентах запрещён.
- Тап-зоны ≥ 44 px, шрифт инпутов ≥ 16 px. Иконки — Lucide.
- Разрешение на push просим только по кнопке и только после первого чекина.
- Любой компонент с датами рендерится после загрузки данных (`useData()`/`useToday()` возвращают пусто на сервере) — иначе ошибки гидратации.
- Проверка перед коммитом: `npm run lint && npm run build`.
