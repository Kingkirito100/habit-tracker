# DECISIONS

| Решение | Почему |
|---|---|
| Next.js 15 + `@serwist/next` (webpack-сборка) | Serwist не работает с Turbopack; `next build` в 15.x по умолчанию webpack. `next-pwa` устарел. |
| Dexie (IndexedDB) | Офлайн-first, без регистрации. `useLiveQuery` даёт реактивность. |
| Настройки в `localStorage`, а не в Dexie | Синхронное чтение + inline-скрипт в `<head>` применяет тему до отрисовки (нет вспышки). |
| Дизайн: Apple снаружи, Fluent внутри | Системный шрифт, скругления, tab bar — Apple; панель навигации периода и командные кнопки — Fluent. |
| Токены в `ui/tokens.css`, Tailwind читает `var(--…)` | Ни одного хардкодного цвета в компонентах; тема и акцент меняются атрибутами `data-theme`/`data-accent` на `<html>`. |
| Серия: `done` +1, `skipped` нейтрален, `missed` обрывает; сегодня без отметки не обрывает | «Серия — отображение, а не угроза». Лимит пропусков: 2 в календарную неделю. |
| Год — 12 плиток (число + полоса), а не 365 ячеек | Читаемость важнее плотности; ячейки ≥ 44 px на телефоне невозможны для года. Тап по плитке открывает месяц. |
| Аккаунты не реализованы | Требуют сервера. Заменено резервной копией JSON; импорт добавляет данные и ничего не перезаписывает молча. |
| Push: клиент + service worker готовы, сервер — нет | Нужны ключи VAPID и планировщик; инструкция в README. Пока приложение открыто, работают локальные напоминания. |
| Агрегаты кешируются по `habitId + период + ревизия данных` | `lib/views.ts`, кеш сбрасывается при изменении entries. |
